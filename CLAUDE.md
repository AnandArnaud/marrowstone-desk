# Working in this repo

A small, self-contained Next.js app. Everything lives at the repo root.

## Run it

```bash
npm install
npm run seed  # creates data/marrowstone.db with sample organizations, users and tickets
npm run dev   # http://localhost:3000
```

`npm run build` type-checks and builds the app. Sign in with any seeded user; passwords are in `db/README.md`.
